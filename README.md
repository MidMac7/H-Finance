# H-Finance
سیستم جامع حسابداری
🌐 راهنمای راه‌اندازی نسخه تحت شبکه (کلاینت / سرور)
نرم‌افزار H-Finance قابلیت اتصال چندین سیستم به صورت همزمان (زنده) به یک دیتابیس مرکزی را دارد. برای این کار باید یک سیستم به عنوان «سرور» و سایر سیستم‌ها به عنوان «کلاینت» تنظیم شوند.

بخش اول: تنظیمات سیستم اصلی (سرور)
این مراحل را فقط روی سیستمی که همیشه روشن است (سیستم مدیریت) انجام دهید:

نصب پایگاه داده: نرم‌افزار PostgreSQL (نسخه 15 یا 16) را دانلود و نصب کنید. هنگام نصب، رمز عبوری که وارد می‌کنید را به خاطر بسپارید.

ساخت دیتابیس: برنامه pgAdmin را باز کنید، روی Databases کلیک راست کرده و یک دیتابیس جدید دقیقاً با نام hfinance_db بسازید.

تنظیمات دسترسی شبکه: به مسیر نصب PostgreSQL (معمولاً C:\Program Files\PostgreSQL\16\data) بروید:

فایل postgresql.conf را با نوت‌پد باز کنید. خط #listen_addresses = 'localhost' را پیدا کرده، # را پاک کنید و آن را به listen_addresses = '*' تغییر دهید.

فایل pg_hba.conf را باز کنید و در خط آخرِ آن، این عبارت را اضافه کنید: host all all 0.0.0.0/0 md5

تنظیمات فایروال: در بخش فایروال ویندوز سرور (Advanced Settings)، یک Inbound Rule جدید برای پورت 5432 (نوع TCP) بسازید و آن را Allow کنید.

راه‌اندازی مجدد: سیستم سرور را یک‌بار ری‌استارت کنید. (همچنین از طریق CMD و دستور ipconfig، آی‌پی این سیستم مثلاً 192.168.1.50 را یادداشت کنید).

بخش دوم: تنظیمات سیستم‌های همکار (کلاینت)

نرم‌افزار H-Finance را روی سیستم‌های دیگر نصب و باز کنید.

در صفحه ورود، روی دکمه 🌐 تنظیمات اتصال به شبکه (سرور) کلیک کنید.

حالت استقرار را روی تحت شبکه قرار دهید.

در کادر آدرس IP سرور، آی‌پی سیستم اصلی (مثلاً 192.168.1.50) را وارد کنید.

پورت را 5432، نام کاربری را postgres و رمز عبور را رمزی که هنگام نصب PostgreSQL روی سرور گذاشتید وارد کنید.

تنظیمات را ذخیره کرده و نرم‌افزار را یک‌بار ببندید و باز کنید. اکنون سیستم شما به سرور متصل است!




وارد سایت Google Cloud Console شوید و یک پروژه جدید به نام فروشگاه خود بسازید.

از بخش APIs & Services، کتابخانه‌های Google Drive API و Google Sheets API را فعال کنید.

به بخش Credentials رفته و یک حساب خدماتی (Service Account) بسازید.

در تب Keys، یک کلید جدید (Create New Key) از نوع JSON بسازید و فایل دانلود شده را روی سیستم خود نگه دارید.

در اکانت گوگل درایو خود، یک شیت جدید (مثلاً با نام PriceList) بسازید.

ایمیل حساب خدماتی (که در فایل JSON نوشته شده) را کپی کرده و شیت خود را با آن ایمیل در حالت Editor به اشتراک بگذارید (Share).

وارد بخش تنظیمات نرم‌افزار H-Finance شده، نام شیت را وارد کنید و فایل JSON دانلود شده را آپلود نمایید.




فعال‌سازی سرویس: ورود به Google Cloud Console، ایجاد پروژه و فعال‌سازی Google Sheets API و Google Drive API.

ساخت حساب خدماتی: ساخت Service Account و ایجاد کلید (Key) با فرمت JSON.

اشتراک‌گذاری شیت: ایجاد فایل اکسل (Sheet) در گوگل درایو با یک نام دلخواه (مانند PriceList) و دادن دسترسی Editor به ایمیل موجود در فایل JSON.

اتصال به نرم‌افزار: آپلود فایل JSON دانلود شده از طریق تب تنظیمات نرم‌افزار و وارد کردن نام شیت.
